# Pulse
Um blog de notícias desenvolvido com JavaScript, Node.js e EJS, criado para conectar leitores às notícias mais relevante

## Sobre o projeto
O Pulse é uma aplicação web de notícias desenvolvida com Node.js, Express e EJS.
O projeto foi criado com foco em praticar desenvolvimento full stack, trabalhando desde a construção das páginas e componentes da interface até as rotas, organização do servidor e gerenciamento dos conteúdos.
A proposta é apresentar notícias de forma simples, rápida e organizada, com uma experiência inspirada em plataformas modernas de conteúdo.

## Tecnologias
```
- Node.js — ambiente de execução
- Express.js — criação do servidor e gerenciamento das rotas
- EJS — renderização das páginas
- JavaScript — lógica da aplicação
- HTML5 — estrutura das páginas
- CSS3 — estilização e responsividade

```

## Funcionalidades
```
- 📰 Listagem de notícias
- 🔎 Busca por notícias
- 📄 Página individual para cada notícia
- 🗂️ Organização por categorias
- 📱 Interface responsiva
- ⚡ Renderização dinâmica com EJS
- 🧭 Navegação entre páginas
- ❤️ Sistema de visualizações e interações
- 📊 Organização de conteúdos com base no comportamento dos usuários

```
